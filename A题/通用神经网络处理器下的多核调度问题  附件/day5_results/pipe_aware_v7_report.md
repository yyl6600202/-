# 问题一：pipe 感知 5 核调度改进（v7）

本轮以 v6 的 100 个官方合法方案为基线，新增 pipe 感知候选生成器（`pipe_aware_search.py`）：粘性 per-op 多维 LPT（plpt）、lineage 级多维 LPT（clpt）、链切段散布（csplit）。核心观察：模拟器让同一核内的多条 pipe 并行、同一核的 Task 串行，因此负载均衡必须按 pipe 分别进行，而不是只均衡总 cycles。每个候选仍由官方事件模拟器评分，只有 Makespan 严格下降才替换基线。

- 算术平均加速比：**3.456677×**
- 几何平均加速比：3.110361×
- 中位数加速比：3.906712×
- p10/min/max：1.2904 / 1.0200 / 5.4115
- 总周期比：3.895693×
- 100 个 case，官方方案校验错误：0
- pipe 感知候选覆盖：100 个 case；接受改进：34 个
